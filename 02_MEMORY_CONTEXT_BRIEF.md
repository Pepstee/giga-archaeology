# Session 02 — Memory & Standing Context

*Read `00_MASTER.md` first. Mission: every AI surface Artiom uses is amnesiac by default; his
orchestrator solved this with handoffs and a KB — his personal tools get the same treatment.
Produce ONE standing-context document and make every surface carry it.*

## Deliverables

1. `CONTEXT.md` — the standing-context document ("the file that makes any AI instantly
   useful"): who he is, what he runs (the orchestrator, v3 build, this programme), current
   priorities with dates, the career clock, active projects, standing decisions already made
   (so no assistant relitigates them — e.g. v2 frozen, fork-clean settled, depth-before-
   breadth). Compact enough to paste anywhere: target one screen.
2. Deployment: Claude (memory and/or project instructions — walk him through), ChatGPT
   (memory + custom instructions field 1), and a note in the doc itself on where copies live.
3. `CONTEXT_PROTOCOL.md` — the maintenance rules: update cadence (suggest: on any standing-
   decision change + a monthly sweep), single-source discipline (this file is canonical;
   surfaces carry copies), and the staleness rule — every copy carries its deploy date, and a
   copy older than a month is presumed stale.
4. **Verification (the recitation test):** after deployment, ask each surface cold: "what do
   you know about my situation and current priorities?" Record what each recites vs the doc.
   Deployment passes only when recitation is faithful.

## Method notes

- Mine `00_MASTER.md`'s operator-context block as the seed, then interview for what's missing
  (personal life context he wants surfaced vs kept out — HIS call, sensitive-data law applies).
- Distinguish three tiers in the doc: IDENTITY (rarely changes), SITUATION (monthly),
  ACTIVE (weekly) — so updates touch one tier, not the whole file.
- Coordinate with Session 01: charter = how to respond; context = what to know. No overlap —
  if a clause could live in either, it lives in the charter.

## Done when

`CONTEXT.md` + protocol exist; both surfaces pass the recitation test; log written; master
table updated.
