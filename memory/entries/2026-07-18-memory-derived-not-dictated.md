The second memory is DERIVED from the corpus, not manually dictated. Telegram/chat capture
stays as an optional mouth, but the pipeline is: export lands -> extractor script -> INGEST
pass files memory-worthy items with prediction triggers. Main job: recall + prediction of
what needs recalling. Rationale: manual seeding depends on diligence and loses exactly the
things worth remembering; the corpus already contains them. Rejected alternative: manual-only
seeding (the original Session 06 plan).
