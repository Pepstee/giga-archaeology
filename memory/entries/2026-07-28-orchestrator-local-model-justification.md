The orchestrator's strongest enduring justification is not generic autonomous coding, which
Codex can already provide as a hosted product capability. It is a provider-agnostic
persistence and assurance layer that can make otherwise session-bound models—including a
local LLM—work continuously through durable state, restart recovery, verification, model
routing and auditable receipts.

Consequences:

- Benchmark v3 against Codex autonomous sessions for hosted software work.
- Separately benchmark continuous local-model operation, where Codex is not a substitute.
- The commercial/career claim is: the orchestrator can turn local or provider CLIs into a
  long-running, auditable software factory without depending on one vendor's autonomous
  session product.
- “Runs indefinitely” remains a target, not a published result, until a long-duration local
  model endurance test proves recovery, bounded resource use, useful throughput and
  correctness.

Source: direct operator insight, 28 Jul 2026.
