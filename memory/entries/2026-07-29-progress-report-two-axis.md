For every project progress report, explicitly separate:

1. implementation progress; and
2. independent certification progress.

Where the project has countable stages, report both as counts and percentages,
for example: `Implementation: 17/17 (100%); independent certification: 9/17
(53%).`

Do not collapse implementation and certification into one misleading
percentage. If either axis cannot be measured honestly, mark it unverified
and explain the missing denominator briefly.

Source: direct operator preference on 2026-07-29.
