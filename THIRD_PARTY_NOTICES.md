# Third-party dependencies

The standalone beta installs these dependencies from the package index; their source is not vendored
in this distribution. Their own licence terms continue to apply.

The exact pinned distributions include license text identifying them as MIT licensed:

- tree-sitter 0.26.0: [upstream license](https://github.com/tree-sitter/tree-sitter/blob/master/LICENSE).
- tree-sitter-bash 0.25.1: [upstream license](https://github.com/tree-sitter/tree-sitter-bash/blob/master/LICENSE).
- tree-sitter-javascript 0.25.0: [upstream license](https://github.com/tree-sitter/tree-sitter-javascript/blob/master/LICENSE).
- tree-sitter-typescript 0.23.2: [upstream license](https://github.com/tree-sitter/tree-sitter-typescript/blob/master/LICENSE).

The validation input is Pallets ItsDangerous 2.2.0 (BSD-3-Clause). Its source is not included in the
beta bundle. The fixture remains unchanged and its licence is retained in the local test input.
This project is not affiliated with Pallets or the Tree-sitter projects.
