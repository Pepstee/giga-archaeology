## Why GitHub was not in the first approval packet

The first packet addressed biographical and employment claims blocking JAA-05. GitHub
requires a different assurance method:

1. repository existence and revision are machine-verifiable;
2. tests and artefacts can prove technical behaviour;
3. commit authorship and AI-generation provenance constrain personal-authorship wording;
4. a repository does not prove deployment, users, commercial impact or unaided coding.

GitHub therefore belongs in the evidence graph, but as repository/test/work-artefact
evidence rather than as unqualified first-person claims.
